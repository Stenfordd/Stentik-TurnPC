1. Odemknout Greenhouse

2. Jak Greenhouse funguje

Základy

  • Rostliny rostou v reálném čase, i offline. Rostou pomaleji než na poli, ale dávají víc.
  • Zalévání: HydroCan 1000. Najeď na rostlinu: když se ukážou čárky, chce vodu. Drž pravé tlačítko, dokud ukazatel nedojde na 100 %. U melounu a dýně klikej radši na okraj hlíny.
  • Plant Diagnostics Tool: pravým klikem uvidíš fázi růstu, čas do uschnutí a stav rostliny.
  • Sklízej jen plně dorostlé. Když rostlina uschne dřív, než ji sklidíš, je mrtvá.
  • Rostliny vedle sebe si dávají bonusy a postihy.

Půda a mutace

  • Půdy: zoraná hlína (farmland), písek, mycelium, soul sand (a end stone). Půdu změníš tak, že rozbiješ hlínu a položíš jiný blok. Soul sand prodává Builder v Hubu.
  • Mutace: kolem prázdného políčka hlíny posadíš správné rostliny a zaléváš. Mutace vyroste na prázdném středu.
  • Mutace použité jako „ingredience“ pro další mutaci nejdou sklidit, jen zničit nebo nechat uschnout. Mutace ale může spawnovat nové, dokud žije.
  • Chloronite se netěží motykou, ale krumpáčem nebo drillem.
  • Kterou půdu která plodina chce, ukazuje crop guide u Carpentera.

Možné zádrhele
  • Veilshroom a mycelium: houby nejspíš chtějí mycelium. Na ironmanovi ho podle hráčů vezmeš těžbou na Crimson Isle (Combat 24). Zkus nejdřív, jestli ho neprodává Builder v Hubu. Bez Veilshroomu nebude Thornshade ani Chloronite.
  • „Oheň“ u Ashwreath: jak přesně se oheň pokládá, ukáže crop guide. Ashwreath potřebuje soul sand.

4. Sundial

Recept: 16× Compacted Sunflower + 5× Chloronite. Dáš ho Samovi a natrvalo se ti odemkne nastavení Crop Speed. Pak nastavíš rychlost pro každou plodinu a nepotřebuješ Rancher's Boots.

5. Farmy a Fermento armor

Fermento armor potřebuje Farming 40 (teď: …). Fermento padá při farmení sugar cane, cactus, mushroom a nether wart v Squash armoru. Na to potřebuješ farmy:

  1. Video: aleck – The BEST Farm Design for EVERY Crop. Cactus, cocoa a cane od 6:17, mushroom od 21:20.
  2. Začni sugar cane: je nejjednodušší a podle fóra stačí plot 1×2. Wiki uvádí 328 Speed a úhel 45°.
  3. Litematica je OK, pokud jen zobrazuje schéma a stavíš ručně. Easy Place a Printer vypni, ty jsou ban.
  4. Rychlost do Sundialu: na lane farmách krátce Rancher's Boots (máš je v Ender Chestu). Přijdeš o Squash set bonus, ale jen na tu dobu.
  5. Fermento armor: /viewrecipe Fermento Helmet (a další kusy). Craftuj po kusech.
  6. Klávesy drž ručně. Makra a autoclickery jsou ban.

Commissions krok za krokem

  1. Gear: Heat armor, Mithril equipment (necklace, cloak, belt, gauntlet), Bee pet (+30 Mining Fortune). Ulož si to jako loadout.
  2. /warp forge (nebo /warp mines, až ho odemkneš) a jdi k Emissary. Vezmi commissions.

    • Mithril: těž šedé, zelené a modré bloky (vlna a prizmarin). Royal Mines, Cliffside Veins.
    • Titanium: náhodně se objeví místo vytěženého Mithrilu (bílý blok jako hladký diorit). Šanci zvyšuje Titanium Insanium.
    • Goblin kills: Goblin Burrows.
    • Event (Goblin Raid): nedá se rerollnout. Čekej na event, SkyHanni má Mining Event tracker (/sh → „mining event“).
  4. Hotovou commission hned odevzdej u Emissary.
  5. Až máš 4 odevzdané, bonus je tvůj. Dál pokračuj, jak dlouho chceš.

Proč foraging

  • Foraging update (0.23, rok 2025) přidal ostrov Galatea, Heart of the Forest (strom perků jako HOTM) a Hunting s atributy, které dávají trvalé staty.
  • Na ironmanovi je to i zdroj coinů: dřevo, Forest Essence, shardy a hlavně levelování petů. Foraging XP jde do aktivního peta i do EXP Share.
  • Jde to hrát v klidu, ping nevadí.

Začátek krok za krokem

Jak se kácí

  • Sweep = kolik logů pokácíš najednou, jako Treecapitator. Je to hlavní stat.
  • Toughness stromu sweep snižuje. Fig má 7, Mangrove 50 (na Mangrove chceš aspoň 50 Sweep).
  • Pořadí kácení: Fig: kmen, pak větve. Mangrove: větve, kmen, pak kořeny. Špatné pořadí je pomalejší.
  • Sekeru jde hodit, ale hozená pokácí jen polovinu.
  • Tree Gift dostane každý, kdo pokácel aspoň 10 % stromu: Foraging XP, HOTF XP, Forest Essence, collection itemy.
  • Forest Whispers z kácení jsou měna na Heart of the Forest perky.

Aktualizovat data

  1. Otevři svůj profil na sky.shiiyu.moe a proklikej všechny záložky (Accessories, Pets, Inventory, Skills, Dungeons, Slayer, Minions, Collections, Misc).
  2. F12 → Console. Napoprvé napiš allow pasting a Enter.
  3. Zkopíruj export skript (tlačítko níž), vlož ho do konzole a dej Enter. Stáhne se soubor skycrypt-….json.
  4. Ten soubor sem přetáhni, vyber přes tlačítko, nebo vlož jeho obsah do pole.
Nebo soubor přetáhni sem. Data zůstávají jen v tomhle prohlížeči.

Export skript (v4)
// SkyCrypt export v4: vlož do konzole (F12 → Console) na stránce profilu na sky.shiiyu.moe
// Tip: před spuštěním proklikej záložky (Accessories, Pets, Inventory, Skills, Minions, Collections...),
// ať si stránka načte i data, která tahá až po kliknutí.
// Stáhne jeden .json soubor se vším, co stránka načetla (data z API + text + názvy itemů).
// Nic neposílá nikam jinam, jen si znovu přečte data, která už SkyCrypt načetl.
(async () => {
  const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
  const out = { url: location.href, time: new Date().toISOString(), api: {}, dom: {} };

  // 1) Rozbalit sbalené sekce (Missing Accessories, Show More Pets, ...)
  const want = /show more|missing|inactive|expand|view all|show all/i;
  for (let pass = 0; pass < 3; pass++) {
    document.querySelectorAll('details:not([open])').forEach((d) => (d.open = true));
    document.querySelectorAll('button, [role="button"], summary').forEach((b) => {
      const t = (b.innerText || b.getAttribute('aria-label') || '').trim();
      if (want.test(t) && !b.dataset.cxDone) {
        b.dataset.cxDone = '1';
        try { b.click(); } catch (e) {}
      }
    });
    await sleep(800);
  }

  // 2) Data z API, která stránka načetla (nejcennější část)
  const urls = new Set(
    performance.getEntriesByType('resource').map((e) => e.name)
      // SkyCrypt v4 bere data přes /_app/remote/... (getCombinedProfileStats a další)
      .filter((u) => /\/_app\/remote\/|__data\.json/i.test(u))
  );
  urls.add(location.origin + location.pathname.replace(/\/$/, '') + '/__data.json');
  out.dom.allResources = performance.getEntriesByType('resource').map((e) => e.name)
    .filter((u) => !/\/api\/(item|head|leather|potion|texture|skin)|\.(png|webp|jpg|gif|svg|woff2?|css)(\?|$)/i.test(u));
  for (const u of urls) {
    try {
      const same = u.startsWith(location.origin);
      const r = await fetch(u, { credentials: same ? 'include' : 'omit' });
      if (!r.ok) { out.api[u] = 'HTTP ' + r.status; continue; }
      const t = await r.text();
      try { out.api[u] = JSON.parse(t); } catch { out.api[u] = t.slice(0, 200000); }
    } catch (e) {
      out.api[u] = 'ERR ' + e.message;
    }
  }

  // 3) Záloha: text stránky a názvy všech itemů z ikonek a tooltipů
  out.dom.text = document.body.innerText;
  const labels = new Set();
  document.querySelectorAll('img[alt], [title], [aria-label], [data-tippy-content]').forEach((el) => {
    for (const a of ['alt', 'title', 'aria-label', 'data-tippy-content']) {
      const v = el.getAttribute(a);
      if (v && v.trim() && v.length < 400) labels.add(v.trim());
    }
  });
  out.dom.labels = [...labels];

  // 4) Uložit jako soubor
  const name = (location.pathname.split('/').filter(Boolean).slice(1).join('-') || 'profil');
  const blob = new Blob([JSON.stringify(out)], { type: 'application/json' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = `skycrypt-${name}.json`;
  document.body.appendChild(a);
  a.click();
  a.remove();
  console.log('Hotovo. API zdroje:', Object.keys(out.api).length,
    '| velikost:', (blob.size / 1e6).toFixed(2), 'MB');
})();
Adam (nebo kdokoli z coopu) může udělat totéž na svém profilu. Když mu pošleš odkaz, data si načte u sebe. Uloží se jen v jeho prohlížeči, tobě se nic nepřepíše.
