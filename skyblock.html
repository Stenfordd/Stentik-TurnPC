1. Odemknout Greenhouse

2. Jak Greenhouse funguje

Základy

  • Rostliny rostou v reálném čase, i offline. Rostou pomaleji než na poli, ale dávají víc.
  • Zalévání: HydroCan 1000. Najeď na rostlinu: když se ukážou čárky, chce vodu. Drž pravé tlačítko, dokud ukazatel nedojde na 100 %. U melounu a dýně klikej radši na okraj hlíny.
  • Plant Diagnostics Tool: pravým klikem uvidíš fázi růstu, čas do uschnutí a stav rostliny.
  • Sklízej jen plně dorostlé. Když rostlina uschne dřív, než ji sklidíš, je mrtvá.
  • Rostliny vedle sebe si dávají bonusy a postihy.

Půda a mutace

  • Půdy: zoraná hlína (farmland), písek, mycelium, soul sand (a end stone). Půdu změníš tak, že rozbiješ hlínu a položíš jiný blok. Soul sand prodává Builder v Hubu.
  • Mutace: kolem prázdného políčka hlíny posadíš správné rostliny a zaléváš. Mutace vyroste na prázdném středu.
  • Mutace má šanci spawnout v každém růstovém stádiu (základ 4 hodiny). Okolní rostliny nemusí přežít, aby mutace dorostla (jediná výjimka je Soggybud), ale setup nech stát kvůli dalším mutacím.
  • Když mutaci znovu zasadíš a projde jedno růstové stádium, už nejde sklidit. Hlídej si čas.
  • Většina běžných mutací (Scourroot, Veilshroom, Shadevine, Dustgrain, Choconut, Gloomgourd) potřebuje jen 2 vstupní plodiny. Na začátku se vyplatí honit z nich „vines“ (Gloomgourd, Pumpkin nebo Sunflower vedle sklízené rostliny dává šanci na vine navíc).
  • Chloronite se netěží motykou, ale krumpáčem nebo drillem.
  • Kterou půdu která plodina chce, ukazuje crop guide u Carpentera. Rozložení si naplánuješ v SkyShards Greenhouse kalkulačce.

Jak to položit: střed nech prázdný (farmland), kolem 8 políček. Tady 6× Coalroot (CR) a 2× Thornshade (TS). Stejným principem uděláš Coalroot (5 Ashwreath + 3 Scourroot) a Thornshade (4 Wild Rose + 4 Veilshroom).

Jestli záleží na tom, kde přesně kus leží, ti řekne Carpenter nebo SkyShards kalkulačka. Okolí nemusí přežít celý růst, ale když ho necháš stát, dá další mutace.
Možné zádrhele
  • Veilshroom a mycelium: houby nejspíš chtějí mycelium. Na ironmanovi ho podle hráčů vezmeš těžbou na Crimson Isle (Combat 24). Zkus nejdřív, jestli ho neprodává Builder v Hubu. Bez Veilshroomu nebude Thornshade ani Chloronite.
  • „Oheň“ u Ashwreath: jak přesně se oheň pokládá, ukáže crop guide. Ashwreath potřebuje soul sand.

4. Sundial

Podle guidu Ironman Sweats je lepší nejdřív dodělat běžné mutace a Sundial nechat až potom. Recept: 16× Compacted Sunflower + 5× Chloronite. Dáš ho Samovi a natrvalo se ti odemkne nastavení Crop Speed. Pak nastavíš rychlost pro každou plodinu a nepotřebuješ Rancher's Boots.

Moje ploty

Vyber plodinu (nebo víc plodin najednou, když je máš v jednom plotu) a klikáním ji přiřaď plotům. Ukládá se to k vybranému hráči. Ploty se znaménkem + jsou ty, které se vyplatí odemknout jako další, protože prodlouží farmu rovně.

    5. Farmy a Fermento armor

    Fermento armor potřebuje Farming 40 (teď: …). Fermento padá při farmení sugar cane, cactus, mushroom a nether wart v Squash armoru. Na to potřebuješ farmy:

    1. Farmy stav podle alecka (tabulka výš): cactus, cocoa a cane od 6:17, mushroom od 21:20.
    2. Začni sugar cane: je nejjednodušší a stačí na něj málo plotů. Speed, úhel a klávesy jsou v tabulce výš.
    3. Designy, které nemusíš přestavovat: Draip farmy na cane, wart, wheat, carrot, potato a růže (video, řady dělej 3 bloky široké, ne 5) a IdkVenom farma na melon a pumpkin (video). Část hráčů má jen 4 farmy: wheat, melon, wart a sun/moonflower nebo růže, jednu na každý vzácný drop.
    4. Než budeš stavět: zkus preset z plot editoru (/desk) a podívej se na /visit farminghub.
    5. Litematica je OK, pokud jen zobrazuje schéma a stavíš ručně. Easy Place a Printer vypni, ty jsou ban.
    6. Rychlost do Sundialu: na lane farmách krátce Rancher's Boots (máš je v Ender Chestu). Přijdeš o Squash set bonus, ale jen na tu dobu.
    7. Fermento armor: /viewrecipe Fermento Helmet (a další kusy). Nasbírej Fermento na všechny 4 kusy a přepni najednou, sety se nesčítají.
    8. Klávesy drž ručně. Makra a autoclickery jsou ban.

    Aktualizovat data

    1. Otevři svůj profil na sky.shiiyu.moe a proklikej všechny záložky (Accessories, Pets, Inventory, Skills, Dungeons, Slayer, Minions, Collections, Misc).
    2. F12 → Console. Napoprvé napiš allow pasting a Enter.
    3. Zkopíruj export skript (tlačítko níž), vlož ho do konzole a dej Enter. Stáhne se soubor skycrypt-….json.
    4. Ten soubor sem přetáhni, vyber přes tlačítko, nebo vlož jeho obsah do pole.
    Nebo soubor přetáhni sem. S uloženým GitHub tokenem (níž) se export rovnou nahraje do repa a uvidí ho i druhý hráč.

    Export skript (v5)
    // SkyCrypt export v5: vlož do konzole (F12 → Console) na stránce profilu na sky.shiiyu.moe
// Tip: před spuštěním proklikej záložky (Accessories, Pets, Inventory, Skills, Minions, Collections...),
// ať si stránka načte i data, která tahá až po kliknutí.
// Stáhne jeden .json soubor se vším, co stránka načetla (data z API + text + názvy itemů).
// Nic neposílá nikam jinam, jen si znovu přečte data, která už SkyCrypt načetl.
(async () => {
  const sleep = (ms) => new Promise((r) => setTimeout(r, ms));
  const out = { url: location.href, time: new Date().toISOString(), api: {}, dom: {} };

  // 1) Rozbalit sbalené sekce (Missing Accessories, Show More Pets, ...)
  const want = /show more|missing|inactive|expand|view all|show all/i;
  for (let pass = 0; pass < 3; pass++) {
    document.querySelectorAll('details:not([open])').forEach((d) => (d.open = true));
    document.querySelectorAll('button, [role="button"], summary').forEach((b) => {
      const t = (b.innerText || b.getAttribute('aria-label') || '').trim();
      if (want.test(t) && !b.dataset.cxDone) {
        b.dataset.cxDone = '1';
        try { b.click(); } catch (e) {}
      }
    });
    await sleep(800);
  }

  // 2) Data z API, která stránka načetla (nejcennější část)
  const urls = new Set(
    performance.getEntriesByType('resource').map((e) => e.name)
      // SkyCrypt v4 bere data přes /_app/remote/... (getCombinedProfileStats a další)
      .filter((u) => /\/_app\/remote\/|__data\.json/i.test(u))
  );
  urls.add(location.origin + location.pathname.replace(/\/$/, '') + '/__data.json');
  // Detail vybraného profilu (skilly s XP, fairy souls...) si vyžádáme i když ho stránka nenačetla
  const pm = location.pathname.match(/\/stats\/([^/]+)\/([^/?#]+)/);
  const anyRemote = [...urls].find((u) => /\/_app\/remote\/[^/]+\/get/.test(u));
  if (pm && anyRemote) {
    const hash = anyRemote.match(/\/_app\/remote\/([^/]+)\//)[1];
    const pl = btoa(JSON.stringify([['__skrao', 1], { profileId: 2, uuid: 3 }, decodeURIComponent(pm[2]), decodeURIComponent(pm[1])]))
      .replace(/\+/g, '-').replace(/\//g, '_').replace(/=+$/, '');
    urls.add(location.origin + '/_app/remote/' + hash + '/getProfileStats?payload=' + pl);
  }
  out.dom.allResources = performance.getEntriesByType('resource').map((e) => e.name)
    .filter((u) => !/\/api\/(item|head|leather|potion|texture|skin)|\.(png|webp|jpg|gif|svg|woff2?|css)(\?|$)/i.test(u));
  for (const u of urls) {
    try {
      const same = u.startsWith(location.origin);
      const r = await fetch(u, { credentials: same ? 'include' : 'omit' });
      if (!r.ok) { out.api[u] = 'HTTP ' + r.status; continue; }
      const t = await r.text();
      try { out.api[u] = JSON.parse(t); } catch { out.api[u] = t.slice(0, 200000); }
    } catch (e) {
      out.api[u] = 'ERR ' + e.message;
    }
  }

  // 3) Záloha: text stránky a názvy všech itemů z ikonek a tooltipů
  out.dom.text = document.body.innerText;
  const labels = new Set();
  document.querySelectorAll('img[alt], [title], [aria-label], [data-tippy-content]').forEach((el) => {
    for (const a of ['alt', 'title', 'aria-label', 'data-tippy-content']) {
      const v = el.getAttribute(a);
      if (v && v.trim() && v.length < 400) labels.add(v.trim());
    }
  });
  out.dom.labels = [...labels];

  // 4) Uložit jako soubor
  const name = (location.pathname.split('/').filter(Boolean).slice(1).join('-') || 'profil');
  const blob = new Blob([JSON.stringify(out)], { type: 'application/json' });
  const a = document.createElement('a');
  a.href = URL.createObjectURL(blob);
  a.download = `skycrypt-${name}.json`;
  document.body.appendChild(a);
  a.click();
  a.remove();
  console.log('Hotovo. API zdroje:', Object.keys(out.api).length,
    '| velikost:', (blob.size / 1e6).toFixed(2), 'MB');
})();
    Adam (nebo kdokoli z coopu) může udělat totéž na svém profilu. Když mu pošleš odkaz, data si načte u sebe. Uloží se jen v jeho prohlížeči, tobě se nic nepřepíše.

    Sdílení přes GitHub

    …

    Stránka si při každém otevření stáhne nejnovější savy obou hráčů z repa (data/skyblock/). Když někdo nahraje export a má uložený token, save se uloží do repa a druhý ho uvidí po obnovení stránky.

    Jak získat token (jednou, asi 2 minuty)
    1. Otevři GitHub → New fine-grained token.
    2. Token name: třeba skyblock-stranka. Expiration: klidně 1 rok.
    3. Repository access: Only select repositories → Stentik-TurnPC.
    4. Permissions → Repository permissions → Contents: Read and write. Nic dalšího nezapínej.
    5. Generate token, zkopíruj ho (začíná github_pat_) a vlož ho sem.

    Adam: buď mu Stentik udělá druhý token stejným postupem a pošle mu ho do DM (dá se kdykoli zrušit), nebo Adam pošle svůj export Stentikovi a ten ho nahraje sám. Bez tokenu jde všechno ostatní, jen se save nenahraje.

    Token se ukládá jen v tomhle prohlížeči, do repa ani nikam jinam se neposílá (jen na api.github.com). Nikdy ho nevkládej do veřejného chatu. Když unikne, smaž ho na GitHubu a udělej nový.
